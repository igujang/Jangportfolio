# 작업물 넣는 곳

프로젝트마다 폴더를 하나씩 만들고, 그 안에 파일을 넣으면 사이트에 자동으로 반영됩니다.

---

## 폴더 이름 규칙

```
번호-영문이름
```

번호는 좌측 리스트에 나올 순서, 영문이름은 주소창에 들어갈 이름입니다.
**띄어쓰기·한글·특수문자 없이**, 소문자와 하이픈(`-`)만 씁니다.

```
01-locl
02-chamisul
03-pledis
```

→ 주소는 `사이트주소/works/locl` 이런 식으로 만들어집니다.

---

## 폴더 안에 넣을 파일

```
public/works/01-locl/
│
├─ thumb.mp4          ← 썸네일 (필수)
│
├─ 01.jpg             ← 상세 페이지 내용
├─ 02.jpg                번호 순서대로 위에서 아래로 나열됨
├─ 03.loop.txt
├─ 04.jpg
└─ 05.vimeo.txt
```

### 1. 썸네일 — `thumb.mp4`

메인 화면 우측 하단에 나오는 움직이는 썸네일입니다.

| 항목 | 규격 |
|---|---|
| 비율 | **1:1 정사각형** |
| 권장 크기 | 800 × 800px |
| 길이 | 5~8초 루프 |
| 소리 | 없음 (무음) |
| 형식 | `.mp4` |
| 용량 | **10MB 이하** (1~3MB 권장) |

> GIF로 갖고 계시면 그냥 넣어두세요. 제가 mp4로 변환해드립니다.
> 용량이 10MB를 넘어도 일단 넣어두시면 압축해드립니다.

### 2. 이미지 — `01.jpg`, `02.jpg` …

상세 페이지에 세로로 쭉 나열될 이미지입니다.

| 항목 | 규격 |
|---|---|
| 가로 폭 | **1400px 이상** (비핸스와 동일) |
| 형식 | `.jpg` / `.png` / `.webp` |
| 이름 | `01`, `02`, `03` … 두 자리 숫자 |

**파일명 순서 = 화면에 나오는 순서**입니다. 순서를 바꾸고 싶으면 파일명 숫자만 바꾸면 됩니다.

### 3. 영상 — `.loop.txt` / `.vimeo.txt`

비메오 영상을 이미지 사이에 끼워 넣습니다.
텍스트 파일을 만들고 **안에 비메오 주소 한 줄만** 적으면 됩니다.

| 파일명 | 어떻게 나오나 |
|---|---|
| `03.loop.txt` | **무한 반복** · 자동재생 · 무음 · 재생버튼 없음 → 모션그래픽, 무빙이미지용 |
| `05.vimeo.txt` | 클릭해서 재생 · 소리 있음 · 컨트롤 있음 → 캠페인 영상용 |

파일 내용 예시:
```
https://vimeo.com/1234567890
```

번호는 이미지와 이어서 붙이면 됩니다. `01.jpg` → `02.jpg` → `03.loop.txt` → `04.jpg` 순서로 나옵니다.

---

## 정리하면

1. 폴더 만들기 (`01-프로젝트영문명`)
2. `thumb.mp4` 넣기 (1:1 정사각형)
3. 이미지를 `01.jpg`부터 순서대로 넣기
4. 영상 자리에는 `.loop.txt` 또는 `.vimeo.txt` 만들고 주소 적기
5. 알려주시면 나머지는 제가 처리합니다

파일명이 좀 틀려도 괜찮습니다. 넣어주시면 제가 정리하겠습니다.
