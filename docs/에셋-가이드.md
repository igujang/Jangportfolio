# 자료 넣는 법

원본은 `Project/` 폴더에 프로젝트별로 넣습니다.
넣은 뒤 `npm run assets` 를 실행하면 웹용으로 자동 변환됩니다.

---

## 썸네일 — 메인 화면 우측 하단에 나오는 것

| 항목 | 규격 |
|---|---|
| **비율** | **1:1 정사각형** (필수) |
| **크기** | **800 × 800px** (화면에는 최대 400px로 나옴. 2배로 만들어야 고해상도 화면에서 선명함) |
| **길이** | 5~8초 루프 |
| **소리** | 없음 (무음) |
| **형식** | mp4 권장 · GIF/mov도 넣으면 자동 변환됨 |
| **용량** | 10MB 이하 (실제로는 1~3MB면 충분) |

**파일명에 `Thum` 을 넣으면 썸네일로 인식합니다.** (대소문자 무관)

```
Project/01 참이슬 오리지날 I BX Renewal (개인프로젝트)/
   └─ Chamisul_Thum.mp4
```

썸네일이 없으면 회색 카드에 번호와 카테고리가 표시됩니다.

---

## 상세 페이지 이미지

| 항목 | 규격 |
|---|---|
| 가로 폭 | **1400px 이상** (비핸스와 동일) |
| 형식 | jpg · png · webp |
| 이름 | 끝에 숫자 — `1.jpg`, `2.jpg` … |

**파일명 끝의 숫자 순서대로 위에서 아래로 나열됩니다.**
순서를 바꾸려면 숫자만 바꾸면 됩니다.

---

## 영상 (비메오)

`.txt` 파일을 만들고 **비핸스에서 복사한 iframe 코드를 그대로** 붙여넣으면 됩니다.

```
Project/01 참이슬 .../
   ├─ 1.txt      ← 영상
   ├─ 2.jpg
   ├─ 3.txt      ← 영상
   └─ 4.jpg
```

iframe 안에 `background=1` 이 있으면 **무한 반복(재생버튼 없음)**,
없으면 **일반 플레이어(클릭 재생, 소리 있음)** 로 나옵니다.

---

## 프로젝트를 새로 추가할 때

1. `Project/` 아래에 폴더를 만들고 자료를 넣는다
2. `scripts/build-assets.mjs` 의 `PROJECTS` 목록에 한 줄 추가한다
3. `npm run assets` 실행
4. `git add -A && git commit -m "작업 추가" && git push`
