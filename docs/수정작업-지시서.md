## 1. 인덱스 레이아웃 — 가장 중요

### 실측값 (1920px 기준)

| 항목 | 값 |
|---|---|
| 제목 크기 | **72px** |
| 제목 자간 | **-0.05em** (= -3.6px) |
| 제목 행간 | **1.0** (72px) |
| **행 피치** | **112px** (제목 72 + 간격 **40px**) |
| 칩 글자 | **14px** |
| 칩 굵기 | **Medium (500)** |
| 칩 여백 | **8px 16px** |
| 칩 모서리 | 완전 둥글게 (pill) |
| **칩 세로 위치** | **제목과 세로 중앙 정렬** (베이스라인 ❌) |
| 썸네일 | **400 × 400px** |
| 썸네일 모서리 | **24px** |
| 썸네일 여백 | 우측 **40px** · 하단 **40px** |

> 칩 중앙 정렬 근거: 제목 top=16 h=72 → 중심 52px / 칩 top=34 h=36 → 중심 52px. 일치.

### 반응형 환산
- 제목 `3.75vw` (72/1920)
- 행 간격 `2.08vw` (40/1920)
- 썸네일 `20.8vw` (400/1920)

### 규칙
- **한 화면에 다 넣으려 하지 말 것.** 스크롤 되는 게 맞다 (많아 보이는 효과).
  → `.index-title` 의 `min(…vh)` 제약과 `xl:py-[4vh]` 축소를 제거한다.
- 번호(`[00]`)도 칩과 같이 세로 중앙 정렬.

### 확정된 예외
- **제목 굵기는 SemiBold(600) 유지.** 참고 사이트는 Regular(400)이지만 사용자가 SemiBold를 지정했다.

## 2. 비메오 · 렌더링 문제

### (a) 로딩 방식 — 전부 미리 불러오기
`components/VimeoBlock.tsx` 가 IntersectionObserver로 **화면에 가까워질 때만** iframe을 올린다.
→ 스크롤 중 만나면 늦게 떠서 완성도가 떨어져 보인다.
**비핸스처럼 처음에 전부 불러오도록** 바꾼다 (지연 로딩 제거).

### (b) 이미지 사이 희미한 회색 줄
간격 0px인 프로젝트(참이슬·locl)에서 이미지 경계에 얇은 회색 선이 보인다.
원인 추정: 이미지 높이가 소수점으로 계산되며 생기는 서브픽셀 틈.
확인 후 수정할 것 (예: `display:block` + 컨테이너 배경색 일치, 또는 `margin-bottom:-1px`).

### (c) 영상 우측 검은 세로 줄
참이슬 프로젝트 "두꺼비 → 장미" 넘어가는 영상의 **우측**에 검은 줄.
원인 추정: `.txt` 의 `width`/`height` 로 계산한 비율과 실제 영상 비율이 미세하게 다름.
→ 비메오 oEmbed API 등으로 실제 비율을 받아 쓰거나, iframe을 살짝 크게 잡고 `overflow:hidden` 처리.

## 4. 썸네일

### (a) 교체가 느린 문제
`WorkIndex.tsx` 의 `<AnimatePresence mode="wait">` 는 **이전 것이 사라진 뒤에** 다음 것을 그린다.
0.32초 + 0.32초 = 0.64초라 빠르게 움직이면 밀린다.
→ **겹쳐서 교차 페이드**되도록 바꾼다 (`mode="wait"` 제거하거나 두 레이어를 겹쳐 놓기).
