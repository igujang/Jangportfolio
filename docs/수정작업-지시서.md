## 완료된 것

### 1. 인덱스 페이지 (`components/WorkIndex.tsx`, `app/globals.css`)

- 참고 사이트 [skiper24](https://skiper-ui.com/v1/skiper24)를 직접 열어 `getComputedStyle`로 실측(`scripts/measure-ref.mjs`) → 1920px 기준 제목 72px, 행간격 40px 적용
- **제목 굵기: Medium(500)** — SemiBold는 너무 두꺼워 보여 사용자가 낮춤 (skiper24는 Regular였는데 최종은 Medium)
- **제목 크기는 모든 프로젝트가 항상 동일** — 프로젝트별 자동 축소(JS)는 시도했다가 "위계가 깨진다"는 피드백으로 폐기. 순수 CSS `clamp()`만 사용, 같은 화면 폭이면 무조건 같은 크기.
- **카테고리 버튼(알약)은 1280px 미만에서 제목 높이의 정확히 50%** ⚠️ 핵심 주의사항:
  - "50%"는 **알약 전체(배경+여백 포함) 높이** 기준이다. 텍스트 폰트만 50%로 줄이면 padding 때문에 알약 크기가 안 줄어드는 함정이 있었음 (실제로 한번 이렇게 잘못 만들어서 사용자에게 지적받음)
  - 계산: `line-height:1` + `padding: 0.08em 0.5em` + `font-size ≈ 0.431 × 제목크기` → 폰트+여백 합이 정확히 제목의 50%
  - `app/globals.css`의 `@media (max-width: 1279px)` 블록 참고
  - **미해결 이슈**: 모바일(390px)에서 알약이 매우 작아져서 "EDUCATION" 같은 긴 카테고리 단어는 글자가 꽤 작다. 사용자에게 이대로 괜찮은지 물어본 상태 — **다음 세션에서 답 확인 필요**. 완화하려면 비율을 55~60%로 올리면 됨 (같은 계산식에서 0.5 대신 0.55/0.6 대입).
- 썸네일: **모바일에서 숨김**, 태블릿(`md:`) 이상에서만 노출
- PC 하단 여백 완전 제거 (썸네일과 텍스트가 겹치지 않으므로 불필요했음)
- 모바일 스크롤 선택 기준선: 화면 정중앙(50%) 대신 **65%** 지점 → 하단 여백(터치 전용) 50vh→35vh로 축소 가능해짐

### 2. 모달 (`components/ProjectModal.tsx`)

- 프로젝트 클릭 시 **비핸스식 모달**로 뜸 (Next.js Intercepting Route: `app/@modal/(.)works/[slug]/`)
- 배경 어둡기 `bg-black/70`, 바깥 클릭 시 `cursor-zoom-out`
- 상단: 프로필 아바타(`/avatar.jpg`) + 제목 + 이름, 우상단 X, 하단 이전/다음
- 주소로 직접 들어오면 `app/works/[slug]/page.tsx`가 같은 모양의 전체 페이지를 보여줌

### 3. 비메오·이미지 (`components/VimeoBlock.tsx`, `components/WorkBlocks.tsx`)

- 비메오 iframe **즉시 로딩** (지연 로딩 제거) — 스크롤 중 늦게 뜨는 문제 해결
- iframe을 컨테이너보다 1px 크게 잡아 가장자리 얇은 선/검은 줄 방지
- 간격 0px 프로젝트(참이슬·locl)는 이미지 사이 `margin-bottom: -1px`로 서브픽셀 회색 선 제거
- `Place_NE` 프로젝트 맨 아래 **"노트폴리오 PICK 선정"** 뱃지 추가 (`work.award` 필드, `scripts/build-assets.mjs`)

`Jand dong ho profile/` 폴더:

- 실제 쓰는 굵기만 서브셋: Regular/Medium/SemiBold/Bold

## 작업 스타일 (다음 세션 참고)

- 참고 사이트 언급되면 **눈대중 말고 반드시 직접 열어서 `getComputedStyle`로 실측**할 것 (`scripts/measure-ref.mjs` 패턴 재사용 가능). 실측 안 하고 만들었다가 여러 번 지적받음.
- 시각적 요구사항("50%로 줄여")은 **정확히 어느 요소를 가리키는지** 확인할 것 — "버튼"이 텍스트인지 배경(알약) 전체인지처럼 오해 소지 있음. 애매하면 스크린샷으로 재확인.
- 수정 후엔 **스크린샷으로 실제 확인** 후 커밋 (npx next build 통과만으로 끝내지 말 것).
- 서버는 세션에 묶여 있어서 이 채팅이 끝나면 같이 죽는다 — 새 세션에서는 `npm run dev`를 직접 새로 띄워야 함.
